# LopeForWhat 🎮

Sebuah proyek game/aplikasi berbasis Python yang dibuat menggunakan pustaka **Pygame**.

## Prasyarat
Sebelum menjalankan proyek ini, pastikan Anda telah menginstal:
* Python 3.11 atau versi yang lebih baru
* Pip (Manajer paket Python)

## Cara Instalasi dan Menjalankan

1. **Klon atau buka folder proyek ini di terminal Anda.**

2. **Buat dan aktifkan Virtual Environment (venv):**
   ```bash
   python3.11 -m venv venv
   source venv/bin/activate
   ```

3. **Instal dependensi yang diperlukan:**
   ```bash
   pip install pygame
   ```

4. **Jalankan aplikasi:**
   ```bash
   python forwhat.py
   ```

## Struktur Proyek
* `forwhat.py` - File utama aplikasi.
* `.gitignore` - Mengabaikan folder `venv` agar tidak terunggah ke GitHub.
* `README.md` - Dokumentasi proyek.
